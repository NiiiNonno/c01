# C01

ローマ字の仮名と倉頡で漢字を、ひとつの入力方法で打てるようにする ibus の入力メソッドです（Ubuntu・Python）。

```
私は普段、ひらがなは…   →   hdi fa tca hjhne,firaganafa …
```

漢字仮名変換（mozc型）は使いません。打ったキーの列を、仮名として読めるか・倉頡として読めるかで解釈し、候補を並べるだけです。

## 動作のしくみ

スペースか記号キーを押すまでのキー列を、ひとまとまり（バッファ）として扱います。

1. バッファ全体が **仮名として読める** なら、仮名が第0候補。
   - ただし全体が倉頡の1コードにもなる場合、**漢字優先リスト**（`priority/*.csv`）にある字だけは仮名より前に出ます（例: `a` → `日`、`あ`）。
   - リストに無い字は仮名の後ろに並びます（例: `ai` → `あい`、`旷`）。
2. そのあとに、**先頭を倉頡で貪欲に切り出し、残りを仮名で読む** 候補が続きます（例: `ai` → `日い`、`giru` → `坮う`、`去る`、`土いる`）。長い倉頡コードのほうが先です。
3. 仮名として読めないときは、倉頡の候補だけが並びます。
4. どれでも読めないときにスペースや数字を押すと、エラー音を鳴らし、何も入力しません（書きかけは残ります）。

倉頡を続けて打つ（`倉頡` = `oiargrmbc`）のは、いまはできません。将来、表で指定した語だけを対象にする予定です。

### キー操作

| キー | 動作 |
|---|---|
| スペース | 選択中の候補を確定（最初は第0候補） |
| ↑ ↓ | 候補を動かす（端でぐるっと回る） |
| 0〜9 | いまのページの、その位置の候補を確定（0 はページの先頭） |
| PageUp / PageDown | 候補のページを送る |
| 記号キー（`,` `.` など） | 選択中の候補を確定し、記号表に従った記号を入れる |
| Enter | 打ったキーのまま確定（英単語用） |
| Esc | 書きかけを捨てる |
| BackSpace | 1文字戻す |
| Ctrl+Shift+M | モードを切り替える（設定で変更可） |

### 片仮名

`-` で始めると、片仮名用の仮名表で読みます。`-katakana` → `カタカナ`。途中の `-` は長音「ー」です。片仮名はスペースで区切ります（`kono -yu-za- ga` → このユーザーが）。

### モード

`direct`（直接入力）／ `kanji`（漢字のみ）／ `hanwa_hira`（和漢混淆・平）／ `hanwa_kata`（和漢混淆・片。平仮名の部分を `hira2kata` の表で片仮名に置き換えるだけ）。

## 表（CSV）

すべて UTF-8。`#` で始まる行と空行は無視されます。同梱の表は `c01/data/` にあり、`~/.local/share/c01/`（`C01_DATA_DIR` で変更可）に **同じ相対パスで置いたものが優先** されます。同梱のものを書き換える必要はありません。

| 場所 | 列 | 説明 |
|---|---|---|
| `romaji/<方式>/hiragana.csv` | 入力, 出力[, 出力後に残す入力] | 平仮名用。促音は `kk,っ,k`（`っ` を出して `k` を残す） |
| `romaji/<方式>/katakana.csv` | 同上 | 片仮名用。拗音（`kya`）など |
| `cangjie/<名前>.csv` | 文字, コード[, first] | 上の行ほど優先。`first` を付けるとそのコードの先頭に入る |
| `symbols/<名前>.csv` | キー, 出力 | 記号キー。仮名・倉頡の打鍵に使う文字は無視される |
| `priority/<名前>.csv` | 文字 | 仮名より先に出す漢字 |
| `hira2kata/<名前>.csv` | 平仮名, 片仮名 | 和漢混淆（片）の置き換え |
| `preedit/<名前>.csv` | キー, 表示 | 入力中の表示（`preedit = "map"` のとき）。倉頡なら部首の字 |
| `variants/<名前>.csv` | 文字, 分類 | `common` / `trad` / `simp` / `shin`。`script` で絞るときに使う |

ローマ字の方式を増やすには、`romaji/<新しい名前>/` に `hiragana.csv` と `katakana.csv` を置き、設定で `romaji = "<新しい名前>"` とします。

同梱の `romaji/hepburn` は **見本** です。実際に使う方式（たとえば は行を `f` で打つなど）は、自分の表に置き換えてください。

### 倉頡データ

`c01/data/cangjie/cangjie5.csv` は [Jackchows/Cangjie5](https://github.com/Jackchows/Cangjie5)（MIT License、`LICENSE-Cangjie5.txt`）の `Cangjie5.txt` を `c01 import-cangjie` で変換したものです。`z` で始まる特殊コードは除いてあります。更新したいときは:

```
c01 import-cangjie /path/to/Cangjie5.txt        # ~/.local/share/c01/cangjie/cangjie5.csv に出る
```

`cangjie/custom.csv` は、Cangjie5 に無い `々`・`ヶ` を足す表です。**コード（`ko`、`kh`）は仮のもの** なので、好きなコードに直してください。

## 入れ方（Ubuntu 24.04）

```
sudo apt install ibus python3-gi gir1.2-ibus-1.0     # 入っていれば不要
cd C01
python3 -m c01 compile             # 表のコンパイル（設定やCSVを変えたらもう一度）
python3 -m c01 try -- hdi ai giru  # 変換の確認
python3 -m c01 install-ibus        # ~/.local/share/ibus/component/c01.xml を作る（--system なら /usr/share/...）
ibus restart
```

そのあと「設定 → キーボード → 入力ソース → ＋ → 日本語」から C01 を追加します。うまく出ないときは、`python3 -m c01 install-ibus --system`（sudo）を試すか、ログ `~/.cache/c01/engine.log` を見てください。

設定は `~/.config/c01/config.toml`。見本は `config.example.toml` です。設定や表を変えたあとは、`c01 compile` を実行すると、次に入力欄へ移ったときに読み直されます。

## 試し打ち（ibus なしで）

```
python3 -m c01 try -- a ai giru
python3 -m c01 try -m hanwa_kata -- kono
python3 -m c01 try            # 対話
```

## テスト

```
python3 -m pytest
```

ibus との接続部分（`c01/ibus_engine.py`）以外は、ibus なしでテストしています。

## 既知のこと・まだ無いもの

- **ibus 接続部分は、開発環境に ibus が無かったため、実機で動かして確かめていません。** 構文と、キー変換などの切り出せる部分だけをテストしてあります。動かないときは `~/.cache/c01/engine.log` を見せてください。
- 仮名でも倉頡でも読める打鍵は、仮名が先になります（例: `egi` は `えぎ`、`法` は2番目）。よく使う漢字は `priority` に足してください。
- 候補の並びは「貪欲な倉頡の切り出し」だけです（`giru` で `去る` が `坮う` の後ろになる件は、使ってみて判断）。履歴による学習はありません。
- 倉頡の連続（`倉頡`）、`script` の字種の絞り込みに使う分類表（`variants`）の同梱データ、設定画面、倉頡以外の版（第三代・速成）の選択は未実装です。
- モード表示は、入力中の候補窓の上（`[和] 12件`）と、ibus のパネルの項目に出ます。GNOME では入力していない間は見えません。
