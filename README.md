# C01

ローマ字の仮名と倉頡で漢字を、ひとつの入力方法で打てるようにする ibus の入力メソッド（Ubuntu・Python）。

```
私は普段、ひらがなは…   →   hdi fa tca hjhne,firaganafaz …
```

漢字仮名変換（mozc型）は使いません。打ったキーの列（ストローク）を、決まった規則で「首辞」と「尾辞」に分けて、候補を並べるだけです。

## 動作のしくみ

スペースか記号キーを押すまでの打鍵を、ひとまとまり（ストローク）として扱います。**どのストロークも、首辞から始まります。**

- **首辞** = ストロークの先頭に来るもの。次のどれか。
  - **head の字**: 倉頡表（と追加字）の字。例: `hdi` → 私
  - **compound の項目**: 熟語（`倉頡`）、送り仮名つきの語（`去る*`）、首辞となる平仮名（`は`、`によって`）
  - **空**（何もない）: 尾辞だけのストローク。**最も優先度が低い**
- **尾辞** = 首辞のあとに続く仮名。仮名表（平仮名か片仮名）で、最後まで読めること。

### 候補の並び（長さで決まる）

候補は、首辞に使った打鍵の**長さが長いものから**並びます。同じ長さなら、compound → head → 空の順。同じ種類の中では、表に書いた順です。

**仮名だから優先される、ということはありません**。平仮名も、書いてあるだけの普通の首辞です。

| 打鍵 | 候補の先頭 | 理由 |
|---|---|---|
| `ni` | に | 首辞リストにある `に` が、倉頡の 夕 と同じ長さで、compound が先 |
| `niyo` | 癶 | `癶` は4打鍵。`に`＋`よ`（首辞は2打鍵）より長い |
| `niyoru` | による | リストの `による*` が6打鍵 |
| `giru` | 去る | 送り仮名リストの `去る*` が4打鍵。`坮`＋`う`（3打鍵）より長い |
| `a` | 日 | `あ` は首辞リストに無いので、空首辞の候補として最後に出る |
| `oiargrmbc` | 倉頡 | 熟語リストの項目（連続した倉頡コード） |

### 片仮名と z

`pure`（単独で構成するもの。いまは片仮名の表）は、ほかの解釈と**並行して、いつも**変換され、候補の**最下位**に並びます。`z` は要りません。

| 打鍵 | 候補 |
|---|---|
| `yu-za-` | …、ユーザー（最下位） |
| `kana` | …、かな、カナ（最下位の2つ） |

末尾に **`z`** を付けると、`z` を除いた残りについて、**仮名（空首辞と pure）だけ**に候補が絞られます（倉頡のコードは `z` で終わらないので衝突しません）。`kanaz` → かな、カナ。`-` による片仮名への切り替えはありません。

### モード

- `direct` 直接入力
- `kanji` 漢字のみ（head の字と、仮名を含まない熟語。仮名は出さない）
- `hanwa` 和漢混淆（上の説明のとおり）

**和漢混淆（片）** は、モードではなく尾辞の表の選び方です: 設定で `tail = "katakana-hepburn"` のように片仮名の表を選びます（首辞のあとの仮名が片仮名で読まれる）。

### キー操作

| キー | 動作 |
|---|---|
| スペース | 選択中の候補を確定（最初は第0候補） |
| ↑ ↓ | 候補を動かす（端でぐるっと回る） |
| 0〜9 | いまのページの、その位置の候補を確定（0 はページの先頭） |
| PageUp / PageDown | 候補のページを送る |
| 記号キー（`,` `.` など） | 選択中の候補を確定し、記号表に従った記号を入れる |
| Enter | 打ったキーのまま確定（英単語用） |
| Esc | 書きかけを捨てる |
| BackSpace | 1文字戻す |
| Ctrl+Shift+M | モードを切り替える（設定で変更可） |

解釈できないストロークでスペース・数字・記号を押すと、エラー音を鳴らし、何も入力しません（書きかけは残ります）。

## 表（CSV・テキスト）

すべて UTF-8。`#` で始まる行と空行は無視されます。同梱の表は `c01/data/` にあり、`~/.local/share/c01/`（`C01_DATA_DIR` で変更可）に **同じ相対パスで置いたものが優先** されます。同梱のものを書き換える必要はありません。

| 場所 | 中身 | 説明 |
|---|---|---|
| `head/<名前>.csv` | 文字, コード[, first] | 首辞の字。倉頡表・追加字。`head` に書いた順に、上の行ほど優先 |
| `tail/<名前>.csv` | 入力, 出力[, 出力後に残す入力] | 尾辞（首辞のあとの仮名）の表。`hiragana-hepburn` / `katakana-hepburn` など。促音は `kk,っ,k` |
| `pure/<名前>.csv` | 同上 | 単独で構成するもの。`katakana-hepburn`（拗音・`-`＝ー を含む）。最低優先度で並行変換される |
| `compound/<名前>.txt` | 1行に1項目 | 複合首辞。熟語・送り仮名つきの語・首辞となる平仮名。`compound` に書いた順に優先 |
| `wildcards/<名前>.csv` | 文字, 展開 | `*` の展開表 |
| `symbols/<名前>.csv` | キー, 出力 | 記号キー |
| `preedit/<名前>.csv` | キー, 表示 | 入力中の表示（`preedit = "map"` のとき） |
| `variants/<名前>.csv` | 文字, 分類 | `common` / `trad` / `simp` / `shin`（`script` で絞るとき） |

平仮名・片仮名の表は、`tail`（1つ）と `pure`（複数可）で別々に選べます。ローマ字の方式を増やすには、`tail/hiragana-<名前>.csv`、`pure/katakana-<名前>.csv` のように置きます。同梱の `hepburn` は**見本**です。前の配置（`cangjie/`、`romaji/<方式>/hiragana.csv`）の表も、見つからなければ読み替えて探します。

### 複合首辞（compound）のリスト

文字列を書くだけです。打鍵列は、漢字を倉頡コード、仮名を仮名表のローマ字に**逆変換して自動で作ります**。

```
倉頡          # 熟語。oiar + grmbc = oiargrmbc と続けて打てる
真ん中        # 「漢かな字」の形も可
ラ行 その他
去る*         # 送り仮名つき。* は wildcards 表で展開: 去ら 去り 去る 去れ 去ろ 去っ
は             # 首辞となる平仮名。ここに書いた仮名だけが、仮名で始まる候補になる
による*
```

- 項目に書いたからといって優先されるわけではなく、一致した打鍵の**長さ**で決まります。
- 仮名の逆変換は、その打鍵を仮名表で**前から読み直して同じ仮名になるものだけ**を採用します（`ほんの` を `hono` と打つと `ほの` と読まれるので、その打鍵列は作りません）。
- `っ` の次に漢字が続く項目（`真っ当`）は、**単独で `っ` を打てる入力**（`ltu` など）が仮名表にあるときだけ打てます。`tt` のように次の子音を残す入力は使えません。項目の最後の `っ`（`去っ`）は、`gitt` のような促音の形も使えるので、`gitte` → 去って と打てます。
- 倉頡表や仮名表に無い字を含む項目は、`c01 compile` のときに警告を出して飛ばします。

### ワイルドカード（`*`）

項目の中の「仮名＋`*`」は、`wildcards/<名前>.csv` で決めた文字の集まりに展開されます。同梱の見本:

| 書き方 | 展開 |
|---|---|
| `る*` | ら り る れ ろ っ |
| `む*` `ぬ*` | ま行／な行 ＋ ん |
| `ぶ*` | ば行 ＋ ん |
| `つ*` | た行 ＋ っ |
| `く*` `ぐ*` | か行／が行 ＋ い |
| `す*` | さ行 |
| `ふ*` | は行 ＋ わ行（わゐうゑを）＋ っ |
| `𛄟*` | わ行（わゐ𛄟ゑを）＋ っ |

展開した文字が仮名表に無いもの（`ゐ` など）は、黙って飛ばされます。**`ふ*`・`𛄟*` と、`く* ぐ* す* つ* ぶ*` は私の推測で書いた見本**なので、実際の使い方に合わせて直してください。

### 倉頡データ

`c01/data/head/cangjie5.csv` は [Jackchows/Cangjie5](https://github.com/Jackchows/Cangjie5)（MIT License、`LICENSE-Cangjie5.txt`）の `Cangjie5.txt` を `c01 import-cangjie` で変換したものです。`z` で始まる特殊コードは除いてあります。

`head/custom.csv` は、Cangjie5 に無い `々`・`ヶ` を足す追加字です。**コード（`ko`、`kh`）は仮のもの**なので、好きなコードに直してください。

## 入れ方（Ubuntu 24.04）

```
sudo apt install ibus python3-gi gir1.2-ibus-1.0     # 入っていれば不要
cd C01
python3 -m c01 compile             # 表のコンパイル（設定やCSVを変えたらもう一度）
python3 -m c01 try -- hdi ni giru  # 変換の確認
sudo python3 -m c01 install-ibus   # /usr/share/ibus/component/c01.xml を作る（c01 のフォルダを指す）
ibus write-cache
ibus restart
ibus list-engine | grep c01        # 出れば登録できている
```

そのあと「設定 → キーボード → 入力ソース → ＋ → 日本語」から C01 を追加します。出てこないときは、ログ `~/.cache/c01/engine.log` を見てください。

設定は `~/.config/c01/config.toml`。見本は `config.example.toml` です。設定や表を変えたあとは、`c01 compile` を実行すると、次に入力欄へ移ったときに読み直されます。

**以前の設定からの移行**: 旧い書き方（`cangjie`、`cangjie_extra`、`mode = "hanwa_hira"`）は読み替えられ、廃止した項目（`kanji_priority`、`hira2kata`）は無視されます（`c01 compile` で注意が出ます）。自分の平仮名表に `-,ー` の行があれば、消してください（`tail` の表に `-` があると、`yu-za-` が平仮名側でも読まれてしまいます）。

## コマンド

```
c01 compile                       表のコンパイル
c01 try -- a ni giru              候補を確かめる（-m でモード、-t で尾辞の表を変えて試せる）
c01 kana FILE                     テキストの平仮名を片仮名に変えて表示（-i で書き換え、-r で逆、-o で出力先）
c01 list                          選べる表の名前と、データ置き場の場所
c01 import-cangjie Cangjie5.txt   Cangjie5 を CSV に変換
```

`c01 kana` は、`compound` のリスト（`去る*` → `去ル*`）を片仮名にするときなどに使えます。`hira2kata` 表は廃止しました。

## テスト

```
python3 -m pytest
```

ibus との接続部分（`c01/ibus_engine.py`）は、偽の ibus を差し込んだ配線のテストだけです。

## 既知のこと・まだ無いもの

- 倉頡の候補は、字の使われやすさでは並べ替えません（表の順）。履歴による学習もありません。
- 項目を逆変換するとき、複数の打鍵列ができることがあります（`し` が `si` と `shi` など）。最大24通りまで。
- `script` の字種の絞り込み用の分類表（`variants`）の同梱データ、設定画面、倉頡の他の版（第三代・速成）の選択は未実装です。
- モード表示は、入力中の候補窓の上（`[和] 12件`）と、ibus のパネルの項目に出ます。GNOME では入力していない間は見えません。
